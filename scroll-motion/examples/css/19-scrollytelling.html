スクロールテリング

固定した図の横を文章が通り過ぎ、ステップに合わせて図が切り替わります。検出はしきい値ベースです。

図1: 要件を演出 ID へ対応づける

図2: CSS を先に、JS は必要な分だけ

図3: reduce とモバイル幅で確認する

  1. 1. 計画

    要求を演出 ID へ対応づけ、既存の CSS 環境に合わせて実装方針を選ぶ。図は文章の補助であり、文章だけで意味が通るように書く。

  2. 2. 実装

    固定は position: sticky で作る。固定区間の高さはステップ数から決め、派手さより読みやすさを優先する。

  3. 3. 検証

    reduce では固定を解除して図を縦に並べる。図とステップの対応が崩れないことを確認する。
