スクロール連動

スクロール量を 0–1 の進捗に変換し、進捗バーを伸ばします。CSS で動かし、非対応環境では JS が同じ動きを再現します。

読み進めるとバーが伸びる

上部のバーがスクロール量に連動します。animation-timeline: scroll() が使える環境では CSS だけで動き、使えない環境では JS が requestAnimationFrame で同じ進捗を再現します。

余白をスクロール

ここまで来るとバーは 100% 付近になります。
