# 品質チェックリスト

スクロール演出を入れる前後で確認する項目。機械的に検出できるものは `scripts/check-*.py` が担当し、ここは判断が必要な項目を中心にまとめる。

## 1. `prefers-reduced-motion`

- [ ] 初期の非表示状態（`opacity: 0` / `visibility: hidden` / `clip-path` / `blur`）は `@media (prefers-reduced-motion: no-preference)` の中だけに置いている。
- [ ] 無限アニメーション（点滅カーソル・マーキー）は reduce で停止する。
- [ ] JS で動かす演出は `matchMedia('(prefers-reduced-motion: reduce)')` を確認し、停止または最終状態の即時表示に切り替える。
- [ ] 停止した結果、情報が欠けない（打ち出しは全文、カウントアップは最終値、横送りは縦積み）。
- [ ] 必須の情報を演出だけで隠し続けていない（演出なしでも読める）。

機械チェック: `python3 scripts/check-reduced-motion.py`

## 2. モバイル（375px 想定）

- [ ] 固定幅（400px 以上）は `@media (min-width: ...)` の中だけに置いている。
- [ ] `100vw` を使っていない（スクロールバー分の横溢れを生む）。
- [ ] 入場演出の移動（`translate3d`）でページが横に広がっていない（必要なら `overflow-x: clip`）。
- [ ] ネストしたスクロール枠（スナップ・横スクロール）は画面高さの 60% 以下で、指のスクロールを奪い続けない。
- [ ] スナップ枠・横送り枠にはキーボードで到達でき、送り操作ができる。
- [ ] タップ対象は 44px 前後の大きさを確保している。

機械チェック: `python3 scripts/check-mobile.py`（静的検出）／実測はブラウザで `document.documentElement.scrollWidth` を確認する。

## 3. 性能

- [ ] `scroll` 購読は `{ passive: true }` + `rAF` で間引き、ハンドラ内で直接 DOM を書いていない。
- [ ] `IntersectionObserver` は検出後に `unobserve` し、要素ごとに Observer を作っていない。
- [ ] アニメーション対象は `transform` / `opacity` / `clip-path` に限定している（`width` / `top` / `margin` を連続更新しない）。
- [ ] `filter: blur()` や大きな `box-shadow` をスクロール連動で動かしていない。
- [ ] 画像シーケンスはフレーム数を絞り（12 前後）、変化時だけ差し替えている。
- [ ] 固定（sticky）区間の高さは必要最小限で、ページ全体を長くしすぎていない。

## 4. アクセシビリティ

- [ ] スクロールスパイ・マーキーなど視覚的な状態は `aria-current` やテキストでも伝えている。
- [ ] 装飾 SVG は `aria-hidden="true"`、装飾テキストは `sr-only` の全文と併記する。
- [ ] 1文字ずつ表示するテキストはライブリージョンにせず、全文を別要素で持つ。
- [ ] カウントアップの確定値は読み上げ可能な形（`sr-only` または確定値の要素）で存在する。
- [ ] `scroll-behavior: smooth` は reduce で無効化している。
- [ ] 固定ヘッダーがフォーカスリングやアンカー移動を隠していない（`scroll-padding-top` を設定する）。

## 5. レイアウト

- [ ] 演出中も本文の行長・行送りが変わらない（`transform` のみで動かしている）。
- [ ] 固定ヘッダーの高さぶんの余白を本文に確保している（隠れたときに内容が飛ばない）。
- [ ] スクロール演出の対象は、内容が確定してから動かす（高さが変わる要素を演出中に再レイアウトしない）。
- [ ] 日本語の折り返しで行が分かれても、行単位のマスク演出が破綻しない（`overflow: hidden` を親に持たせる）。

## 6. 判定

機械チェックが通っていても、次は目視で確認する。

1. reduce を有効にして、情報が欠けず・動かず・操作できること。
2. 375px 幅でカード内デモと詳細デモを操作できること。
3. スクロールを途中で止めたときに、要素が半端な状態で読みにくく残らないこと。
4. キーボードだけで目次・スナップ枠・リンクを操作できること。
