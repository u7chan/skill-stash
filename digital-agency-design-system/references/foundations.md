# 基本デザイン（レイアウト / アイコン / リンク / カラー設計）

トークンの値そのものは `references/tokens.md` を参照。ここは**どう使うか**の規則。

## レイアウト

### グリッド

- 基準は **12 カラム**。マージン・カラム・ガターで構成する。
- 主要なレイアウト: 1 カラム / 2 カラム（9:3, 3:9, 8:4, 4:8, 6:6）/ 3 カラム（3:6:3, 4:4:4）/ 4 カラム（3×4）。
- 管理画面などでは左に固定幅のナビゲーション領域を置き、その右端からグリッドを張る。
- カラムは可変、ガターまたはマージンを固定にして**リキッド**にする。固定幅レイアウトにしない。

### ブレークポイント

DADS の作例は **1 つ**のブレークポイントで 2 レイアウトを提供する。

| 区分 | 幅 |
| --- | --- |
| モバイル・タブレット | 768px 未満 |
| デスクトップ | 768px 以上 |

### CSS グリッドを使うときの制約

- `order` と `grid-placement` は**視覚的な並び替え専用**。DOM 順・読み上げ順・タブ順は変わらない。
- 視覚順序を DOM 順から大きく外れる位置に変えるなら、そもそも文書構造の並びを直す。

## アイコン

### 4 つの配置仕様

| 名称 | 位置 |
| --- | --- |
| フロントアイコン | ブロックレベルボックスの先頭 |
| リードアイコン | 行ボックスの先頭（テキストシーケンスの一部） |
| テールアイコン | 行ボックスの末尾（テキストシーケンスの一部） |
| エンドアイコン | ブロックレベルボックスの末尾 |

### 使い方の規則

- **必ずラベルと組み合わせる。** アイコン単体で意味を伝えない。
- ラベルと併記するアイコンには代替テキストを付けない（`<img alt="">`、インライン SVG は `aria-hidden="true"`、`aria-label` を付けない）。
- **例外**: 意味の種別そのものを伝えるアイコン（通知バナーの info / warning / error / success、緊急バナーなど）は、ラベルがなくても種別を伝えている唯一の要素なので `role="img"` + `aria-label`（例: `aria-label="インフォメーション"`）を付ける。
- リンクのアイコンは**リンクのクリック領域に含める**。アイコンだけ別の `<a>` にしない。
- やむを得ずアイコン単体で使う場合は、本来のラベルを代替テキストにし、操作要素なら **44×44 CSS px 以上**のターゲットを確保する。
- アイコンの色は背景に対して **4.5:1 以上**（非テキスト専用と保証できる場合のみ 3:1 以上）。

### 素材

`assets/icons/*.svg`（120 種、24×24、`fill` は `currentColor` に正規化済み）。
`fill/_line` の 2 系統がある。展開・再取得は `python3 scripts/setup-icons.py`。

**注意**: `<img>` で読み込んだ SVG の `currentColor` は SVG 自身の `color`（既定は黒）で解決され、ページの `color` は継承しない。色を変えたい場合は `.dads-icon-mask` を使う。

```html
<!-- 既定（黒系で描画される） -->
<img class="dads-icon" src="assets/icons/search_line.svg" alt="" width="24" height="24">

<!-- CSS の color を反映させる（mask 方式） -->
<span class="dads-icon-mask" aria-hidden="true"
      style="--dads-icon-src: url('assets/icons/search_line.svg')"></span>
```

```html
<!-- ラベル併記（推奨） -->
<button class="dads-button" data-type="solid-fill" data-size="md">
  <img class="dads-icon" src="assets/icons/search_line.svg" alt="" width="24" height="24">
  検索
</button>

<!-- 単体利用（最終手段。代替テキストとターゲットサイズ必須） -->
<button class="dads-button" data-type="outline" data-size="md" aria-label="検索">
  <img class="dads-icon" src="assets/icons/search_line.svg" alt="" width="24" height="24">
</button>
```


## リンクテキスト

- 通常テキストと区別するため、**色と下線（またはそれ以外の非色情報）を必ず併用**する。
- リンクの目的が分かるテキストにする。「ここ」「こちら」「もっと詳しく」だけのリンクは不可。複数並ぶ場合は `aria-label` で区別する。
- 色は 未訪問=青 / 訪問済み=マゼンタ を既定とし、`dads-global.css` で `:any-link` / `:visited` に実装済み。
- ステート: hover は下線を太く + わずかに暗い青、active はオレンジ、focus は黒 + 黄の 2 重リング。
- 新しいタブを開くリンクには末尾アイコンと「新しいタブを開きます」等の代替テキストを付ける。ウェブページ以外へのリンクはファイル形式・容量をテキストで明記する。
- ターゲットサイズは **24×24 CSS px 以上**（インラインで高さが足りない場合は上下 4px ずつの余白で担保）。

## カラー設計

- プリミティブカラーを直接使わず、**キーカラー / ニュートラルカラー / セマンティックカラー**を経由する。
- キーカラーは `--color-key-*` の定義差し替えだけで変更する。各コンポーネント CSS は `--color-key-*` を参照している。
- プライマリーカラーは主要な背景色とのコントラスト比 **4.5:1 以上**を維持する必要がある（CTA のラベル等に使うため）。
- セカンダリーカラーはプライマリーと同色相で明度違い。隣接表示は 3:1 以上、テキスト用途は 4.5:1 以上。
- ターシャリーカラーはセカンダリーと反対の明度。
- セマンティックカラーは意味を固定する（成功=緑、エラー=赤、警告=黄/橙）。エラーを緑で示すのは不可。色相を保つ範囲で明度・彩度は調整してよい。
- アクセントカラーは多用しない。装飾以外・機能を持つ要素に使う場合はコントラスト比を確保する。
- 背景色が白・黒以外のときは、その背景でのコントラスト比を必ず再確認する。

## エレベーション

- 高さを持つ要素は**ボーダーで 3:1 以上のコントラストを確保する**。影でコントラストを取らない。
- hover で高さを変える要素は、通常時より 1 段階以上上のレベルを確保する。
- オーバーレイ表示（ダイアログ等）は、下にある最も高いレベルより **2 段階以上上**。
- オーバーレイシェードは「その下で最も高いレベルをちょうど覆う」位置に敷き、シェード上の要素はレベル 0 にリセットする。モードレスダイアログではシェードを使わない。
- 高低差は広く取ると強調、狭く取ると管理画面向けの抑制表現になる。どちらかに統一する。

## 角の形状

- 5 段階（なし / スモール / ミディアム / ラージ / フル）から、コンポーネント単位で固定する。
- 同じ半径でも、小さい図形ほど丸く見え、大きい図形ほど角が立って見える。縦横比に応じて調整する。
- 角丸は強調表現にも使えるが、多用すると階層が壊れる。

## 余白

- 基準単位 **8 CSS px**。`8 / 24 / 64` のように 3〜5 段階に絞る。
- 関連の強い要素は小さく、弱い要素は大きく離す。
- 階層が上位なほど周囲の余白を大きく取る。
- 空白文字や `text-align: justify` で位置を揃えない。
