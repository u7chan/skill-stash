# 最終調整

構造や仕様を変えず、視覚的な不整合と操作上の問題を解消する。

## 調整対象

余白・整列、文字サイズ・ウェイト、アイコンサイズ・配置、ボーダー・角丸、ボタンの高さ・操作領域、色・コントラスト、一貫性、操作状態、不要な文言・装飾・コンテナ。

## レスポンシブ

対象プロダクトが対応するサイズで確認する。指定がなければ一般的なWeb UIの代表例として375px、768px、1440pxを使える。固定ブレークポイントにはしない。必要に応じ320 CSS px相当のリフローや中間幅も確認する。専用システムに不要な端末対応を追加しない。

## 実データに近い状態

長い日本語・英数字、URL・パス、件数増減、空データ、数値の桁数、スクロール、テーマ切り替えのうち変更範囲に関係するものを確認する。

## 修正と再確認

レビューで特定した問題を優先し、最小限の修正を行う。問題のない箇所を好みで変更せず、既存トークンを優先し、依存追加や無関係なリファクタリングを避ける。

修正後は対象と影響範囲を再確認し、必要に応じて変更前後の画像を比較する。指摘の解消、新しい不整合、操作性の悪化、他の画面サイズへの影響を確認する。

重大な問題を解消し依頼品質を満たしたら終了する。具体的な改善が説明できない追加調整を行わない。
