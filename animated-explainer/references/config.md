# 入力形式

UTF-8のJSONで、題材の `content.json` と任意の `theme.json` を作る。エンジンを編集せずに題材と見た目を差し替えられる。

## content.json

| キー | 内容 |
| --- | --- |
| `title` | 必須。題材のタイトル。短い問いでもよい |
| `subtitle` | 任意。前提や条件が必要な場合に使う |
| `lang` | 任意。HTMLの言語タグ。既定は `ja`。操作名は日本語と英語に対応 |
| `nodes` | 図に出る要素の配列。必須 |
| `links` | 要素間の関係を示す線の配列。任意 |
| `scenes` | 再生順のシーンの配列。必須 |

`nodes` の各要素に `id`、`label`、`x`、`y` を指定する。`x` と `y` は図の左上を原点とした中心位置（0〜100%）。`width` は図に対する幅（既定は30%）。補足が必要なら `detail` を加える。文字や矢印が収まるように、要素は図の端から間隔を取る。

`links` の各要素に `id`、`from`、`to` を指定する。`from` と `to` は異なるノードのID。`label` は線上に出す短いラベル。`style` に `dashed` を指定すると破線になり、`directed` を `false` にすると矢印を省く。IDは各配列内で一意とする。

### シーン

シーンごとに表示状態を指定する。途中へ移動した場合も同じ内容を表示できる。

| キー | 内容 |
| --- | --- |
| `caption` | 必須。図で示す主張を一文で書く |
| `nodes` | 必須。表示するノードIDの配列。空配列なら図なし |
| `links` | 表示するリンクIDの配列。両端のノードを同じシーンに含める |
| `duration` | 表示秒数。既定は3秒 |
| `effect` | ノードが現れるときの動き。`fade`（既定）、`rise`、`drop`、`left`、`right`、`pop`、`zoom` |
| `focus` | 輪郭を強調する、表示中のノードIDの配列 |
| `flow` | マーカーを移動させる、表示中のリンクIDの配列 |
| `details` | 表示中のノードIDをキーとする補足の差し替え。空文字でその補足を消す |
| `metrics` | キャプションを補足する数値や状態。文字列の `label` と `value` を持つオブジェクトの配列 |
| `code` | `lines` にコードの行、任意の `highlight` に強調する行番号（1始まり）の配列を指定。必要なら `label` で言語名や「擬似コード」を表示 |

短いキャプションとノード名を使い、各シーンで強調する要素を絞る。コードは縦型画面で読める行長に整える。

`metrics` と `code` は指定したシーンだけに表示され、無いシーンではその高さの分だけ図が広がる。同じ内容を複数のシーンで出したい場合は、それぞれのシーンに書く。

縦型の画面に収まる量の目安は、タイトル2行、1シーンに同時に出すノード4個、コード6行、メトリクス3個。これを超えると図が狭くなり、要素同士が重なる。タイトルとキャプションは長いと自動で縮小するが、内容を削るほうを優先する。

## 操作

再生・一時停止は再生ボタンかスペースキー、前後のシーン移動は前へ／次へボタンか ← → キー、先頭へ戻るのは最初からボタン。HTMLは外部ファイルを読まないので、`file://` で直接開いても動く。

## theme.json

`--theme` で指定する。省略時は端末の明暗設定に合わせてグレーを基調に表示する。

| キー | 内容 |
| --- | --- |
| `mode` | `system`（既定）、`light`、`dark` |
| `light` / `dark` | モードごとの色指定。必要な項目だけ記入できる |
| `radius` | 枠の角丸を表す数値（0〜24） |

色のキーは `background`（画面）、`surface`（図やコードの面）、`text`（文字）、`muted`（補足）、`border`（線）、`accent`（強調と動くマーカー）。値は `#RRGGBB`。文字と背景、強調と周囲の色のコントラストを確認する。
