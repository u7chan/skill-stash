# 入力形式

UTF-8のJSONで、題材の `content.json` と任意の `theme.json` を作る。エンジンを編集せずに題材と見た目を差し替えられる。

## content.json

| キー | 内容 |
| --- | --- |
| `title` | 必須。題材のタイトル。短い問いでもよい |
| `subtitle` | 任意。前提や条件が必要な場合に使う |
| `lang` | 任意。HTMLの言語タグ。既定は `ja`。操作名は日本語と英語に対応 |
| `nodes` | 図に出る要素の配列。必須 |
| `links` | 要素間の関係を示す線の配列。任意 |
| `scenes` | 再生順のシーンの配列。必須 |

`nodes` の各要素に `id`、`label`、`x`、`y` を指定する。`x` と `y` は図の左上を原点とした中心位置（0〜100%）。`width` は図に対する幅（既定は30%）。補足が必要なら `detail` を加える。`icon` にアイコン名を書くと、ラベルの前にアイコンが付く。文字や矢印が収まるように、要素は図の端から間隔を取る。アイコンを付けるとラベルの幅が増えるので、長い名前は `width` を広げるか短くする。

`links` の各要素に `id`、`from`、`to` を指定する。`from` と `to` は異なるノードのID。`label` は線上に出す短いラベル。`style` に `dashed` を指定すると破線になり、`directed` を `false` にすると矢印を省く。`blocked` を `true` にすると、線が途中の × で止まり、先は薄い点線になる（止める・拒否する経路）。`flow` に入れると玉は × まで進んで止まり、× が揺れて低い音が鳴る。IDは各配列内で一意とする。

### アイコン

テンプレートに入っている名前だけ使える（違う名前は build.py が使える名前を挙げて止める）。

| 種類 | 名前 |
| --- | --- |
| 人・やり取り | `user`、`users`、`chat`、`bot`（エージェント）、`mail`、`send` |
| 置き場・機械 | `server`、`database`、`cloud`、`globe`（公開の Web）、`monitor`、`phone`、`file`、`folder`、`package`、`layers`、`network` |
| 処理・道具 | `code`、`terminal`、`settings`、`search`、`filter`、`refresh`、`zap`、`link`、`download`、`upload`、`clock`、`eye`、`list`、`idea`、`arrow` |
| 守り・結果 | `lock`、`key`、`shield`、`alert`、`check`、`x`、`block` |

### シーン

シーンごとに表示状態を指定する。途中へ移動した場合も同じ内容を表示できる。

| キー | 内容 |
| --- | --- |
| `caption` | 必須。図で示す主張を一文で書く |
| `nodes` | 必須。表示するノードIDの配列。空配列なら図なし |
| `positions` | 任意。表示中のノードIDをキーに `x` / `y` を持つオブジェクト。シーンごとに位置を変えられ、同じIDのノードは滑って移る。省略した軸は `nodes` の値を使う |
| `links` | 表示するリンクIDの配列。両端のノードを同じシーンに含める |
| `duration` | 表示秒数。既定は3秒 |
| `effect` | ノードが現れるときの動き。`fade`（既定）、`rise`、`drop`、`left`、`right`、`pop`、`zoom` |
| `focus` | 輪郭を強調する、表示中のノードIDの配列。先頭のノードをキャプションの吹き出しの尾が指す（無ければ中央） |
| `flow` | データが流れる、表示中のリンクIDの配列。線は破線が `from` から `to` へ動き続け、玉がシーンの表示中くり返し渡る。玉は線ごとに 0.6 秒の拍で渡り、ある線の `to` から始まる線は次の拍で続く（並列する線は同時に流れる）。配列の順は問わない。流れの連鎖の後に 1 拍休んでくり返す。玉が部品を出るときと着くときに拍に合わせて音が鳴り、着いた部品が小さく弾む |
| `sound` | シーンの頭の効果音。`chime`（既定）、`alert`（問題・失敗）、`success`（解決・結果）、`none` |
| `details` | 表示中のノードIDをキーとする補足の差し替え。空文字でその補足を消す |
| `metrics` | キャプションを補足する数値や状態。文字列の `label` と `value` を持つオブジェクトの配列。`icon` を付けると `label` の前に出る |
| `code` | `lines` にコードの行、任意の `highlight` に強調する行番号（1始まり）の配列を指定。強調行は `flow` の色を薄く敷く。必要なら `label` で言語名や「擬似コード」を表示 |
| `phase` | 変更前と変更後の対のシーンに付ける。`before` で「変更前」、`after` で「変更後」の札を図の上に出す |
| `points` | まとめのシーンの要点。文字列か、`text` と任意の `icon`（既定は `check`）を持つオブジェクトの配列。図の場所に順に現れるので、`nodes` は空にする。2〜4 個が目安 |

短いキャプションとノード名を使い、各シーンで強調する要素を絞る。コードは縦型画面で読める行長に整える。

`positions` は `{"api": {"x": 40, "y": 30}}` のように書く。位置を変えないノードは省略でき、同じIDのノードは表示されたまま新しい位置へ滑る。

`metrics` と `code` は指定したシーンだけに表示され、無いシーンではその高さの分だけ図が広がる。同じ内容を複数のシーンで出したい場合は、それぞれのシーンに書く。

縦型の画面に収まる量の目安は、タイトル2行、1シーンに同時に出すノード4個、コード6行、メトリクス3個。これを超えると図が狭くなり、要素同士が重なる。タイトルとキャプションは長いと自動で縮小するが、内容を削るほうを優先する。

## シーンの切り替え

切り替えは 3 拍で進む。`effect` は新しく現れるノードの動きだけを決め、ほかはテンプレートが受け持つ。

1. 退場（0.2 秒）：次のシーンに無いノード・線・吹き出し、変わる数値の札とコード、まとめの要点が、薄れながら少し退く。進むときは上へ、戻るときは下へ抜ける。同時に風切り音が鳴る（進むときは上がり、戻るときは下がる）
2. 移動と登場：次のシーンにも残るノード（同じ id）は、元の位置から新しい位置へ 0.48 秒で滑る。線は動いているノードに付いたまま動く。新しいノードは `effect` で現れる
3. 描き出し：新しい線は出どころから円が広がるように描かれる。数値の札は左から順に、コードは下から入ってから強調行が左から塗られる。「変更前」から「変更後」の札はめくれる。強調の輪郭や補足の差し替えも、パッと変えずに薄れて入れ替わる

玉は、ノードが滑り終わってから流れ始める。切り替えの途中で次の操作をすると、途中の動きを打ち切ってすぐ次へ移る。端末の「視差効果を減らす」が有効なときは、切り替えの動きを付けず、流れの玉も移動させずに線の途中へ静止表示する。

## 操作

画面には再生用のボタンを出さない。スライドの外の右下に、再生の状態（再生中・停止中）、シーン番号、歯車だけを置き、操作はキーと画面のクリックで行う。右下はスライドに重ならないので、スライドだけを切り抜いて録画できる。

| 操作 | キー・クリック |
| --- | --- |
| 再生・停止の切り替え | スペース |
| 前後のシーン | ← → キー、画面の左 3 分の 1 のクリックで戻り、それ以外で進む |
| 最初へ | Home キー |
| 音のオン・オフ | M キー |

歯車のメニューで「自動再生」（開いたときに再生を始めるか）、「音」、「トリム用の枠」、「テーマ」（自動・ライト・ダーク）を切り替える。設定はそのブラウザに覚える。テーマの「自動」は端末の明暗設定に合わせる。見る人がテーマを選ぶまでは、theme.json の `mode` が既定になる。トリム用の枠は録画の切り抜きの目印で、スライドのすぐ外側に 1px の線を引く。線の内側で切れば線は映らない。M を押すと右下に「音: オン」などが短く出る。停止は先へ進むのを止めるだけで、表示中のシーンの玉と破線は流れ続ける。

スライドの下端のゲージはシーンの数で区切ってあり、全体のどこにいるかと、次のシーンまでの時間を示す。見終わったシーンは埋まり、今のシーンは再生中に伸び、停止中はその位置で止まる。番号はスライドの外の右下だけに出し、録画に焼き込まない。HTMLは外部ファイルを読まないので、`file://` で直接開いても動く。

効果音は Web Audio で合成するので音声ファイルは要らない。ブラウザは最初のクリックかキー操作まで音を出させないため、開いた直後の自動再生は無音で、クリックかキー操作の後、再生中に Home で最初に戻ると頭から音つきで流れる（停止中に Home を押した場合は最初のシーンに戻るだけで、再生はスペース）。

## theme.json

`--theme` で指定する。省略時は端末の明暗設定に合わせてグレーを基調に表示する。

| キー | 内容 |
| --- | --- |
| `mode` | `system`（既定）、`light`、`dark`。見る人が歯車のメニューでテーマを選ぶまでの既定 |
| `light` / `dark` | モードごとの色指定。必要な項目だけ記入できる |
| `radius` | 枠の角丸を表す数値（0〜24） |

色のキーは `background`（画面）、`surface`（図やコードの面）、`text`（文字）、`muted`（補足）、`border`（線）、`accent`（強調・流れる破線・ゲージ）、`flow`（データの玉・コードの強調行・まとめのアイコン。画面で唯一の色味で、既定はオレンジ）。値は `#RRGGBB`。文字と背景、強調と周囲の色のコントラストを確認する。
