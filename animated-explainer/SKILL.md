# Animated Explainer

依頼された題材を、ブラウザで再生できる単体のHTMLにする。縦型（9:16）の画面にタイトル、図、キャプションを配置し、本文を理解するのに役立つ場合に数値やコードを添える。画面は幅に合わせて拡大縮小する。

1. 何を理解できれば説明が完了するかを一文にする。対象の資料やコードがある場合は、実際の処理や用語を確認する。
2. 題材に合う順を選ぶ。処理なら「入力 → 変化 → 結果」、比較なら「同じ条件 → 違い → 結果」、構造なら「全体 → 部分 → つながり」を出発点にする。結論に必要な要素から順に出す。
   - 最後のシーンはまとめにする。`points` に要点を 2〜4 個並べ（それぞれ内容に合うアイコンを付ける）、キャプションは結論を一文で書く。
   - 変更前と変更後を見せるときは 2 枚を対にする。同じノードを同じ位置に置き、変わる部分（足した部品、止める線など）だけを変える。`phase` で「変更前」「変更後」の札を付け、キャプションも同じ形でそろえる。メトリクスやコードの有無と行数が違うと図の高さが変わって位置がずれるので、2 枚でそろえる（コードなら変更前と変更後の該当行を同じ行数で並べる）。止める線は `blocked` にする。
3. 各シーンで伝えることを一つに絞る。図の出現、線上の移動、状態ラベルの変化など、キャプションの内容が目で追える変化を選ぶ。データ・要求・応答が部品の間を移るシーンでは、その線を `flow` に入れる。流れる線は破線が向きに沿って動き続け、破線と別の色の玉がシーンを表示している間くり返し渡る。キャプションは伝えたい一文を強調する吹き出しで、シーンごとに弾んで出て、尾は `focus` の先頭のノードを指す。指したいノードを `focus` の先頭に置く。待ち時間は読む量に合わせる。短い説明では全体で15〜25秒を目安にする。
4. 変化の意味に合う演出を選ぶ。同じ動きを続けると単調になるので、シーンの意味が変わるところで変える。シーンの切り替えはテンプレートが受け持つ。消える要素が短く退き（進むときは上へ、戻るときは下へ）、次のシーンにも残る部品は新しい位置へ滑って移り、新しい線は出どころから描き出される。つながりを見せたい部品は、シーンをまたいで同じノード（同じ id）を使い続ける。別の id にすると、退いてから出直すので、別物に見える。位置を変えるときは、シーンの `positions` でノードの x / y を指定する。

   | 伝えること | `effect` |
   | --- | --- |
   | 次の段階へ進む | `rise` |
   | 前提・前の段階から入る | `drop` |
   | 左右の比較・分岐 | `left` / `right` |
   | 状態の変化を強調する | `pop` |
   | 全体から細部へ寄る | `zoom` |
   | 補足だけを差し替える | `fade` |

   音も鳴らす。シーンの切り替わりとノードの出現で効果音が鳴る。玉は線ごとに 0.6 秒の拍で渡り（並列する線は同時）、部品を出るときと部品に着くときに拍に合わせて鳴る（着くたびに音が上がり、着いた部品が小さく弾む）。玉がくり返すあいだ音もくり返す。シーンの頭の音は `sound` で意味に合わせる。

   | シーンの意味 | `sound` |
   | --- | --- |
   | 問題・失敗・危険を見せる | `alert` |
   | 解決・結果がうまくいったことを見せる | `success` |
   | それ以外（既定） | `chime` |
   | 頭の音を鳴らさない | `none` |

5. [入力形式](references/config.md)を参照して題材ごとの `content.json` を作る。部品の種類が一目で分かるよう、ノードに `icon` を付ける（人・エージェント・サーバー・DB・ファイルなど）。種類を見分けたい部品にはそろえて付け、飾りだけのアイコンは付けない。数値の札（metrics）にも付けられる。数値が例示なら図やキャプションに明記する。`code` はコードの解説が要るシーンだけに置き、根拠になる行に絞る。擬似コードにはその旨を添える。
6. `python <スキルのディレクトリ>/scripts/build.py content.json <出力先>.html` で生成する。見た目の指定があれば独立した `theme.json` を用意し、コマンドに `--theme theme.json` を追加する。配布するHTMLには設定とプレイヤーが含まれる。
7. 可能ならブラウザで最初から最後まで確認する。図とキャプションが一致するか、画面上で文字や線や吹き出しの尾が重ならないか、尾が狙ったノードを指すかを見る。操作は画面にボタンを出さず、キーと画面のクリックで行う（スペースで再生と停止を切り替え、← → で前後、Home で最初へ、M で音、画面の左側のクリックで戻り右側で進む）。スライドの外の右下に再生の状態とシーン番号が出る。自動再生・音・トリム用の枠（録画の切り抜きの目印）・テーマ（自動・ライト・ダーク）は右下の歯車のメニューにある。スライドの下端にはシーンの数で区切ったゲージがあり、全体の位置と次のシーンまでの時間が見える。録画ではスライドだけを切り抜く前提なので、番号や操作の表示をスライドの中に置かない。これらが働くか、玉が破線と見分けられるか、右下の表示がスライドに重ならないかを確認し、HTMLを渡す。ブラウザの決まりで、最初のクリックかキー操作までは音が出ないので、渡すときに「最初の再生は無音。クリックかキー操作の後、再生中に Home で最初に戻ると頭から音つきで流れる」ことを添える。
