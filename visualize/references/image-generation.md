# Image Generation

画像生成は、テキスト図よりも**人間向けの視覚表現そのものに価値がある場合**に使う。

## Good fits

- Concept diagram
- Infographic
- Presentation visual
- Architecture illustration
- Educational illustration
- Visual summary
- 視覚的な比喩を使った説明

## Capability requirement

画像生成は、**GPT系の画像生成に対応した環境で、実際に画像生成ツールが利用可能な場合だけ**実行する。

以下のどちらかに該当する場合は生成しない。

- 現在のモデルがGPT系ではない
- GPT系でも画像生成ツール・機能が利用できない

その場合は、画像生成できないことを短く明示する。画像を生成したと装ったり、存在しない画像へのリンクを返したりしない。

代替表現が理解に役立つ場合のみ、ASCII、Mermaid、HTMLなど利用可能な形式へフォールバックする。ユーザーが画像そのものを必要としている場合は、勝手に別形式を完成品扱いしない。

## Selection rules

画像生成を選ぶのは次の条件を満たす場合。

- 視覚的な印象や直感的理解が重要
- 記事、資料、説明用など人間が見る用途
- テキスト図では情報を伝えにくい
- 現在の環境で画像生成が利用可能

「図なら何でも画像にする」運用にはしない。

## Prompt direction

画像生成時は、最低限次を明確にする。

- 何を理解させる画像か
- 主要要素と関係
- 強調すべきポイント
- 不要な装飾
- 必要なら画面比率や用途

技術図では、見栄えのために存在しないコンポーネントや関係を追加しない。
