# Quality Gate

最終評価は点数ではなく状態で行う。

目的は文章を際限なく磨くことではなく、明確な問題が解消された地点で停止することである。

## Gate 1: Meaning fidelity

既存文書では最優先。

確認:

- 事実を変えていない
- 数値や固有名詞を変えていない
- 条件や例外を落としていない
- 不確実性を勝手に変えていない
- 判断の強さを変えていない
- 元文にない因果や経験を作っていない
- 書き手固有の自然な特徴を不要に消していない

一つでも違反があれば REVISE。

## Gate 2: Readability

確認:

- 主述や修飾関係を一読で追える
- 参照語の対象が明確
- 論理条件の入れ子が必要以上に複雑でない
- 列挙が埋没していない
- 一文に役割を詰め込みすぎていない
- 読点で無理に構造を補修していない

長文であること自体は不合格理由にしない。

## Gate 3: Information density

確認:

- 読者がすでに知っている一般論を長く講釈していない
- 同じ主張を言い換えて繰り返していない
- 見出しで分かる内容を本文で実況していない
- 結論の前に不要な助走がない
- 情報不足を説明量で埋めていない

簡潔さのために必要な条件や根拠を削ってはいけない。

## Gate 4: Scanability

確認:

読者が文書の用途に応じて必要な情報へ早く到達できる。

例:

- 結論
- 変更点
- 判断
- 必要な行動
- コマンド
- 期限
- リスク

スケルトン通読で大きな流れを追えない場合は REVISE。

## Gate 5: Logical clarity

確認:

- 主張と根拠が対応している
- 判断と条件が対応している
- 因果を述べるなら間の仕組みが追える
- 例外の適用範囲が明確
- 一つの例を過度に一般化していない
- 事実、推測、意見、決定を不必要に混同していない

## Result

### PASS

次をすべて満たす。

- 高影響の未解決問題がない
- 修正が新しい問題を生んでいない
- 追加変更の価値を説明できない
- ユーザーの依頼範囲を満たしている

PASSしたら終了する。

### REVISE

明確に改善すべき問題が残る。

問題の種類を特定し、必要な箇所だけ修正して再確認する。

### BLOCKED

材料不足により、安全に意味や構造を確定できない。

可能な範囲の成果を返し、必要な確認事項を本文と分ける。

## No score chasing

自己採点の数値を上げるために反復しない。

数値評価をユーザーが明示的に求めた場合でも、スコアは説明補助に留め、スコア到達を自動終了条件にしない。
