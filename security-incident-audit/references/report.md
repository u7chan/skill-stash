# 点検結果の出力形式

以下を、証拠が確認できた範囲だけ埋める。推測は「仮説」と明記する。

## 1. 緊急報告
- インシデント対応が必要な兆候: あり / なし / 未確認
- 概要・発見時刻・影響が疑われる範囲:
- 直ちに引き継ぐ相手・証跡保全の状況:
- 承認が必要な対処:

## 2. 実施範囲
- 点検日・対象期間・タイムゾーン:
- 調査対象の組織・部署・環境:
- 利用できた情報源・利用できなかった情報源:

## 3. 資産別点検表
| 資産/部署 | 公開/サービス分類 | ログ期間・保持期間 | ログ | アカウント | パッチ | 判定 | 担当者 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| ... | ... | ... | ... | ... | ... | ... | ... |

判定値: `確認済み` / `要対応` / `未確認` / `対象外`。
`確認済み` は実施状況であり、完全な安全の保証ではない。

## 4. 発見事項
各発見事項に次を記す:
- ID / 重要度 / 対象資産
- 観測した事実・基準との差異 / 対象期間 / 証拠の保管場所
- 考えられる説明（正常要因を含む）/ 未確認事項
- 推奨アクション / 実施責任者 / 期限 / 承認状態

## 5. 未確認・制約
- アクセス権不足、未収集ログ、保存期間超過、管理台帳未整備など
- 追加調査・サービス提供者への照会が必要な事項

## 6. 再発防止・改善候補
- 公開範囲 / MFA / 権限 / API連携 / ログ収集・保持 / データ最小化

## 7. 証拠一覧
- 識別子 / 取得元 / 取得日時・タイムゾーン / 検索条件 / 保存先 / 取扱制限

個人情報、認証情報、生ログは報告本文に貼り付けず、アクセス制御された保管先を参照する。
